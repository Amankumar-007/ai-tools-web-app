# Environment setup

1. Copy `.env.example` to `.env.local` (it is git-ignored) and fill in the values.
2. Put every API key in a plain server variable, e.g. GEMINI_API_KEY, OPENROUTER_API_KEY.
   NEVER prefix a secret with NEXT_PUBLIC_: those values are embedded in the JavaScript sent to every visitor.
3. Payments (Razorpay) switch on only when ALL of RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, RAZORPAY_WEBHOOK_SECRET, SUPABASE_SERVICE_ROLE_KEY and NEXT_PUBLIC_SUPABASE_URL are set. See GROWTH.md.
   Add the webhook https://YOUR-DOMAIN/api/razorpay/webhook (events: payment.authorized, payment.captured, order.paid, refund.processed).
4. Create the admin login with `node scripts/admin-setup.cjs` and paste the printed lines into .env.local.
5. Restart the dev server after changing environment variables.

See SECURITY.md for the full list of protections and the production checklist.
